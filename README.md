# Лапа Помощи (Lapa Pomoshi)

Цифровая платформа для координации помощи бездомным животным: задачи, передержки, карточки животных, чат, календарь, медиатека и профили участников.

## Статус проекта
MVP / активная разработка.

## Роли
- Волонтёр — видит ленту задач, откликается, ведёт коммуникацию в чате, заполняет профиль.
- Куратор / Организация — создаёт задачи и запросы передержки, управляет откликами, ведёт карточки животных.

## Основные модули (frontend)
- Auth: регистрация, логин, подтверждение email, восстановление пароля
- Профиль: редактирование профиля, рейтинг/отзывы, “Мои питомцы”
- Животные: создание/просмотр/редактирование карточек, загрузка фото
- Задачи: лента, фильтры, создание/редактирование, отклики, завершение
- Передержки: создание запросов передержки, просмотр
- Чат: список чатов, сообщения (REST + SignalR)
- Календарь: визуализация моих задач по датам
- Медиатека: статьи/материалы (ReferenceBook) + фильтры

## Технологии
- Next.js (App Router), TypeScript
- CSS Modules
- react-hook-form + zod
- SignalR (чат)
- REST API backend (см. переменные окружения)

## Требования
- Node.js 18+ (рекомендуется 20+)
- npm
